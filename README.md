# Pokédex

A Flutter Pokédex powered by PokéAPI and Riverpod.

- Browse Pokémon in a trading-card grid.
- Add, edit, or remove nicknames.
- Save favorites with heart buttons and an expandable panel.
- Filter by type or select All to reset.
- Refresh the list and switch between light and dark themes.

## Run

```sh
flutter pub get
flutter run
```

Nicknames and favorites are kept during the current app session.
