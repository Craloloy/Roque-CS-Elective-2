# Current model implementation

The original photographs were visual references during modeling. The release no longer displays them, samples their pixels, or bundles the references directory. The Gallery contains clean front and back model renders only.

The active products are the university pin, printed ID sling, separate plain navy ribbon, clear landscape case, caduceus pin, round-neck PE set and collared PE set. Both PE sets include long pants. The header uses the supplied official university seal; the pin uses that seal as a rotating front surface texture. Geometry is stylized and approximate, not a photogrammetry scan.

Run flutter test --no-pub tool/render_models.dart after geometry changes to keep product-card images consistent with the 3D viewer. See README.md for the academic prototype and payment limitations.
